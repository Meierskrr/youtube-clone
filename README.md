# YouTube Clone

Projeto desenvolvido com o objetivo de reproduzir a interface da página inicial do YouTube, utilizando HTML5 e CSS3.

## Tecnologias utilizadas

- HTML5
- CSS3
- Flexbox

## Funcionalidades e elementos implementados

- Cabeçalho com campo de pesquisa e ícones.
- Barra lateral de navegação.
- Grade de vídeos com miniaturas, títulos e informações dos canais.
- Tooltips em elementos da interface.
- Organização dos estilos em arquivos CSS separados.

## Objetivo

Praticar e aprimorar conhecimentos em desenvolvimento web, estruturação de páginas HTML e estilização com CSS.
